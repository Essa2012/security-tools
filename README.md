# 🛡️ Security Tools

أدوات أمنية بلغة Python لتعلّم اختبار الاختراق.

## 📦 الأدوات

### 1. Web Security
- http_analyzer_v7.py - تحليل Headers + SSL + Cookies
- xss_scanner_v2.py - كشف XSS
- sqli_scanner.py - كشف SQL Injection
- sqli_auto_v3.py - SQL Injection تلقائي
- ssrf_scanner.py - كشف SSRF
- cors_scanner_v2.py - كشف CORS
- jwt_scanner.py - تحليل JWT
- open_redirect_scanner.py - كشف Open Redirect
- web_fuzzer.py - اكتشاف مسارات
- directory_brute.py - اكتشاف مجلدات
- blind_sqli.py - Blind SQL Injection

### 2. Reconnaissance
- subdomain_finder.py - اكتشاف النطاقات الفرعية
- subdomain_takeover_v3.py - كشف Subdomain Takeover
- port_scanner_v2.py - فحص المنافذ
- takeover_scanner_v2.py - كشف Takeover

### 3. OSINT
- osint_dashboard.py - Dashboard شامل
- password_checker.py - فحص كلمات السر

### 4. Mobile
- apk_scanner.py - فحص APK
- apk_scanner_v2.py - فحص APK متقدم

### 5. Other
- brute_force.py - تخمين كلمات السر

## 🚀 الاستخدام

python3 http_analyzer_v7.py https://example.com
python3 subdomain_finder.py example.com
python3 xss_scanner_v2.py "https://example.com/search?q=test"
python3 sqli_scanner.py "https://example.com/product?id=1"
python3 osint_dashboard.py all example.com
